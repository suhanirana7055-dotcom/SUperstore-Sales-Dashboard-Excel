# Superstore Sales Dashboard - Excel

## Project Overview
An interactive Excel dashboard created to analyze Superstore sales,
profit, orders, and quantity using Pivot Tables, Pivot Charts,
KPIs and interactive filters.

## Tools & Technologies
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Excel Dashboard
- Data Analysis

## Key KPIs
- Total Sales
- Total Profit
- Total Orders
- Total Quantity

## Dashboard Analysis
- Monthly Sales Trend
- Sales by Region
- Category-wise Analysis
- Product Analysis
- Interactive Filters/Slicers

## Key Skills Demonstrated
- Data Analysis
- Pivot Tables
- Pivot Charts
- KPI Dashboard Creation
- Data Visualization
- Excel Reporting
